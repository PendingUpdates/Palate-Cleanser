# Palate Cleanser

![Palate Cleanser fruit-bowl artwork](docs/assets/Palate-Cleanser.png)

Palate Cleanser is in development for reviewing potentially unwanted applications. The current version does not audit endpoints, assess production inventories, or remove applications. Do not provide production inventory or private endpoint data.

## Safety

The former Windows scanner and remover are archived and disabled in the supported entry points. The old PowerShell launchers and build entry stop without scanning or modifying a host. Archived code is not sandboxed and remains unsafe if deliberately run. **Do not execute the archived Windows scripts.**
